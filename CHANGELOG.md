# Changelog

All notable changes to ToolPicker are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html)
from v1.0.0 onward.

## [1.0.0] — 2026-05-27

First stable release. The public API is now committed under semver: breaking changes require a major-version bump.

### Added
- Stable public surface: `ToolPicker`, `FunctionSchemaSource`, `OpenAPISource`, `MCPSource`, `MergedSource`, `OpenAIEmbeddings`, `HashEmbedder`, `CachedEmbedder`, `EmbeddingNNIntent`, `IntentExample`, `IntentClassifier`, `Retriever`, `BM25Retriever`, `SemanticRetriever`, `reciprocal_rank_fusion`, `pack_to_budget`, `count_tokens`, `default_serialise`, `Tool`, `ToolSource`.
- CHANGELOG.md (this file) back-filling v0.1 → v0.7 changes.
- PyPI trusted publishing via OIDC (`release.yml`); no API tokens stored.
- Classifier bumped to `Development Status :: 5 - Production/Stable`; added `Typing :: Typed` and Python 3.13 classifier.

### Removed
- `RetrievalHit` dataclass. Defined in `toolpicker.types` since v0.1 but never used internally; retrievers return `list[tuple[str, float]]` directly. Dead export; removed before 1.0 locks the surface.

### Flagged as still unstable (may change without major bump)
- Default RRF weights (`bm25_weight`, `semantic_weight`, `intent_weight` all `1.0`). v0.6 evals show uniform weights underperform pure semantic on some corpora; learned-weight defaults may land in a v1.x without breaking the kwarg surface.
- Synthetic eval-harness corpus shape (`SYNTHETIC_CASES`, `SYNTHETIC_TRAIN_EXAMPLES`). These ship in `evals/` for the comparison runner; not part of the installed wheel.

## [0.7.0] — 2026-05-27

### Added
- mkdocs-material docs site at `https://ashwinugale.github.io/toolpicker/`.
- 6-page nav: Home / Quickstart / Concepts / Sources / Eval / API.
- API reference autogenerated via mkdocstrings.
- GitHub Actions workflow (`docs.yml`) deploys on every push to main via `actions/deploy-pages`.
- README links to the docs URL with a badge.

### Changed
- `ToolPicker` and `EmbeddingNNIntent` docstring Example blocks rewritten as fenced code instead of doctest-style to avoid mkdocstrings autoref interpreting literal list output as cross-reference targets.

## [0.6.0] — 2026-05-27

### Added
- `IntentClassifier` Protocol + `IntentExample` dataclass + `EmbeddingNNIntent` reference impl. k-NN over unit-normed embedded queries; sum-aggregation per `tool_id`.
- `ToolPicker(intent_classifier=...)` kwarg wires the classifier in as a third RRF ranking. `intent_weight` kwarg alongside `bm25_weight` / `semantic_weight` (all default 1.0).
- `evals/benchmarks/synthetic_train.py` — 50 `IntentExample` entries (2 per tool × 25 tools), disjoint from the 200-case test corpus (enforced by test).
- `evals/compare.py` extended with `intent-only` and `bm25+semantic+intent` strategies.
- 14 new tests (`test_intent.py` + router integration).

### Changed
- `evals/benchmarks/gorilla.py::_load_tools` now builds description as `functionality | domain | description` instead of raw description. Closes the v0.5 use-case-vs-architecture gap on the Gorilla benchmark — Gorilla hybrid p@1 climbed ~29% relative (0.068 → 0.088).

## [0.5.0] — 2026-05-26

### Added
- BM25 stopword filtering. `DEFAULT_STOPWORDS` (curated ~60 tokens) applied at the tokeniser. `BM25Retriever(stopwords=...)` and `ToolPicker(bm25_stopwords=...)` overrides; `frozenset()` reproduces pre-v0.5 behaviour.
- `evals/benchmarks/synthetic.py` rewritten — 25 tools across 6 domains, 200 cases at exactly 8 per tool spanning 8 named phrasing styles (direct, param, conversational, imperative, stopword_heavy, paraphrase, indirect, domain_context).
- `evals/benchmarks/toolbench.py` real parser. Scans `data/toolenv/tools/<Cat>/*.json`, mints one `Tool` per `api_list` entry. Cases from `data/instruction/G{1,2}_query.json`. Default caps `max_tools=2000` / `max_cases=500`.
- `evals/benchmarks/gorilla.py` real parser. One `Tool` per line of `data/api/{hub}_api.jsonl`; cases by joining `questions_{hub}_0_shot.jsonl` ↔ `response_{hub}_Gorilla_FT_oracle.jsonl` on `question_id` with substring api_name matching.
- `evals/compare.py` multi-strategy runner — bm25-only / semantic-only / hybrid-rrf strategies, JSON + console table.
- Parser tests via on-disk `tmp_path` fixtures (no dataset download needed in CI).

### Changed
- Reverted the v0.4 `bm25_weight=0.0` test workaround in `test_router.py` — stopword filtering fixes the root cause.

## [0.4.0] — 2026-05-23

### Added
- `evals/` sibling directory (not shipped in the wheel) with `Benchmark` Protocol, runner, metrics.
- `SyntheticBenchmark` — 10 tools / 15 cases across 5 domains. Cheap CI path; works without API keys.
- `ToolBenchAdapter` / `GorillaAdapter` as env-gated stubs (real wiring in v0.5).
- Four metric families: `precision_at_k`, `mean_reciprocal_rank`, `latency_stats` (p50 / p95 / mean), `tokens_saved`.
- `python -m evals` CLI with `--benchmark / --embedder / --k / --token-budget / --output / --seed`.

## [0.3.0] — 2026-05-23

### Added
- `OpenAPISource(spec, *, validate=True)` — parses OpenAPI 3.0 / 3.1, accepts dict / JSON path / YAML path. `$ref` resolution via `jsonref.replace_refs(..., proxies=False)`. Tool id = `operationId` or `{method}_{path}` fallback. Path / query / header / cookie / body params flatten to one namespace.
- `MCPSource(mcp_tools=[{...}])` sync constructor + `async from_client(session)` classmethod for live introspection.
- `MergedSource(*sources)` concatenates tools from multiple sources with cross-source duplicate-id detection.
- 23 new tests across `test_openapi_source.py` / `test_mcp_source.py` / `test_merged_source.py`.

## [0.2.0] — 2026-05-23

### Added
- `pack_to_budget(tools, *, token_budget)` greedy first-fit packer (skip-and-continue).
- `count_tokens(tool)` via `tiktoken cl100k_base` with `ceil(len(json) / 4)` fallback.
- `default_serialise(tool)` produces the OpenAI function-call envelope.
- `CachedEmbedder(embedder, *, cache_path=None, autosave=True)` — sha256-keyed disk cache, atomic-ish save (tmp + rename), corrupted-file recovery.
- `ToolPicker.select(query, *, k, token_budget=None)` kwarg — packs after RRF fusion, then caps at k.
- 27 new tests across `test_packer.py` / `test_cache.py`.

## [0.1.0] — 2026-05-23

### Added
- `Tool` dataclass + `ToolSource` Protocol (runtime_checkable).
- `EmbeddingProvider` Protocol, `OpenAIEmbeddings` (lazy-imports openai, batches at 2048), `HashEmbedder` (deterministic test double).
- `FunctionSchemaSource` — parses OpenAI function-call schema dicts, with or without the `{"type": "function", "function": {...}}` envelope.
- `Retriever` Protocol, in-house `BM25Retriever` (~80 LOC, k1=1.5, b=0.75, Robertson-Sparck-Jones+1 idf smoothing), `SemanticRetriever` (cosine over embedded descriptions).
- `reciprocal_rank_fusion(rankings, *, weights, rrf_k=60)` — weighted RRF.
- `ToolPicker(source, *, embedder=None, ...)` facade — 4× over-fetch + RRF.
- Hand-curated 20-tool corpus + tests across 5 domains.

## [0.0.1] — 2026-05-23

### Added
- Project scaffolding. `pyproject.toml`, `src/toolpicker/` layout, `py.typed` marker.
- Tooling: `uv`, `ruff` (lint + format), `mypy --strict`, `pytest`.
- Test scaffold with `utf-8-sig` `.env` loading in `conftest.py`.
- `LICENSE` (MIT), `README.md`, `.gitignore`.
